# Changelog

## 0.1.0

The first release.

- Registers the Learn MCP server (`@foreverlearning/learn-mcp` 0.1.0, docs of November 23, 2026) with VS Code, bundled in the extension and run with VS Code's own runtime.
- **Learn: Set API key** and **Learn: Remove API key** keep your server key in VS Code's secret storage and hand it to the running server, with no restart.
- **Learn: Open the quick start** and **Learn: Copy the first-tutor prompt**.
- Settings for the API host and your Learn assignment.
